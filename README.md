# おかえりの灯 — 試作版

雪の町で、道に灯りをともして回る幼馴染のふたり。遊んでいると、ちょっとあたたかい気持ちになれる短編RPGを目指した試作です。

## 遊び方

このフォルダーの `index.html` を Chrome または Edge で開いてください。インストール不要、インターネット接続不要です。ZIPの場合は、先にすべて展開してください。

- 矢印キー / WASD：移動
- E / Enter：調べる、会話を進める（文字が出ている途中なら、押すと全文を表示）
- Q：トウマとニナの先頭を交代
- J：旅の手帳（今日の用事と、次の行き先）
- 地面や人物をクリック：そこまで移動。調べられる対象には近づいて話しかけます
- OPの映像は自動で最後まで流れます。飛ばしたい時だけ、右下の「スキップ」か Esc
- 右上の「音 OFF」：音楽・効果音・環境音を有効にします。もう一度押すと止まります
- 戦闘：「たたかう」→ トウマ → ニナの順にコマンドと対象を選びます。矢印キーで選択、Enter / Zで決定、Esc / Xで一段戻る。通常戦は「にげる」で離脱できます

## 物語

トウマとニナは、十二年前の大雪の晩に、同じ荷車の列で親を亡くしました。町の人たちに手分けして育てられ、大人になった今は、町はずれの空き家を直して一緒に暮らしています。仕事は「灯守（ひもり）」。雪で消える道の方角を知らせ、魔獣を退ける「護りの灯火」の番をします。恋人ではありません。たぶん、まだ。

| 話 | 題 | 出来事 |
|---|---|---|
| 1 | ふたり分の帰り道 | 師匠抜きで初めて森の灯台へ。倒木、灯りの橋、雪の精霊。夕方の荷車に間に合わせる |
| 2 | 雪の下の宝物 | コハルが三人目として加わる。水番のリツが町へ戻る。水路の戸棚から、子どもの頃の小箱が出てくる |
| 3 | 届かなかった声 | 水路の板の交換中に、氷が外れて濁流。ニナを助けたあと、トウマが言ってしまう |
| 4 | 君の好きなもの | 口をきかない三日目。町の人たちがそっと背中を押す。夜、三日ぶんの話をする |
| 5 | あの日の雪だるま | 右にしか曲がらない古いそりを直して、丘の子どもたちへ。十何年ごしの白状 |
| 6 | 春からの手紙 | ニナに、南の灯工房から三週間の研修の誘い。湖の向こうの町ミナモへ小旅行 |
| 7 | この家の最初の冬 | 窓の隙間風を直す休日。写真の裏から出てきた「椅子、二つ」の書きつけ |
| 8 | 護りの灯火をつなぐ夜 | 祭りの前日の吹雪。丘の小屋に四人が取り残される。今度は、全員を帰す |
| 9 | 言葉にする帰り道 | 護りの灯火祭り。何も直さない夜。護りの灯火の下で、関係を選ぶ |
| 10 | ふたりで選ぶ明日 | 選んだ結末で過ごす最初の一日（六通り） |

第3話の喧嘩は、その夜には片づきません。第4話の夜に持ち越します。

第9話の護りの灯火の下で、結末を選びます。隠し好感度はありません。

- **ニナと**：トウマから告白／ニナから告白（恋人になる）、名前はまだつけない（今のまま）
- **コハルと**：姿の見えないコハルを探しに行き、話を聞いたあとでもう一度選ぶ。「三人でいる今を選ぶ」（三人で仲良く）か、「聞いたままにはしない。ニナにも全部話す」（葛藤の末、ニナに「コハルなら、ゆるせるよ」と言われて二人を大事にする） 三つ目の「コハルの気持ちに、応える」は、コハルひとりを選ぶ結末（ニナは相棒のまま、二人を送り出す）。この結末の専用スチルはまだありません。
- **後日譚**：恋人になる結末（トウマから／ニナから／コハルひとり／二人とも）は、最終話の最後の画面に「後日譚を読む」が出ます。戦闘も用事もない、甘い時間だけの読み物で、何度でも最初から読めます。台本は `script/epilogue-*.js`。

### コハル

ユラの診療所で修業中の薬師見習い。二人の二つ年下の妹分で、物語の最初から、二人と同じ家に暮らしています（ニナの部屋で寝台を分け合い、食卓では踏み台に座ります）。二人が並んでいるのを見るのがいちばん好きで、トウマのことはそれとは別に、ほんのり好き。三人でいたいので、ときどき小さなやきもちを焼きます。第1話の朝、家を出た二人と鉢合わせして広場で見送ります。**第2話から、薬箱を持つ三人目として同行します**（第1話で、橋の上でニナの指が動かなくなったという報告を受けて、サエが決めます）。第3話のあと、ニナが休む十日間は、トウマと二人きりで道を回ります。 第2話で、ユラの跡を継ぐ「薬の番」として灯守に加わります。灯守はもともと火の番（ニナ）・剣の番（トウマ）・薬の番の三人一組で、薬の番の札は十二年空いていました。当番の日は町の中も三人で歩きます。二人きりの夜の場面では、診療所の夜番に出ているか、先に眠っています。

顔（通常・笑顔・照れ・ふくれ顔・泣きそう）、町に立つ姿、三人目として歩く姿、戦闘の姿が入っています。第1話から広場の南に立っていて、話ごとに違うことを言います（丘へ登っている間と、三人で歩いている間は除く）。第2話と第3話の水路、第5話の丘、第8話の丘、コハルの二つの最終話では、三人目として後ろをついて歩きます。

戦闘では**自分で指示を出す三人目のヒーラー**です。一緒に歩いている時の戦闘で後ろに立ち、剣も火も持たない代わりに薬草で二人を支えます。「てあて」（MP不要の小さな回復）、「くすり」から凍傷の軟膏（回復と冷えの解除）、薬湯（全員回復）、守りの塗り薬（そのターンの傷を半分）、滋養丸（MPを渡す）、気付け薬（倒れた仲間を起こす）。全体攻撃は後ろのコハルにも半分届きます。トウマとニナの二人が倒れると、コハルが立っていても負けです。

絵の制作記録は `assets/KOHARU-ART-NOTES.md` にあります。

三人の家では、食卓の右側の扉からコハルの部屋に入れます。寝台、薬草棚、机、思い出の箱を調べられ、手前の扉から食卓へ戻れます。食卓には、最初からコハルの踏み台も置いてあります。

### 思い出の絵（スチル）

各話に一枚と、結末ごとに一枚、計15枚の絵が、物語の決まった場面で表示されます。一度見た絵は、タイトルの「思い出の絵」から見返せます。見た記録は保存データとは別に残るので、「はじめから」や章選択をしても消えません。

どの場面でどの絵が出るかは [assets/stills/README.md](assets/stills/README.md) を参照してください。

- **帰り道の寄り道**：第2・4・6・8話で、出来事のあとに短い話を一つ読めます。読むと、その夜の食卓、祭り、最終話に会話が増えます。
- **二人で考える**：第4話の贈り物、第5話のそり、第7話の窓、第8話の吹雪の合図は選択式。うまくいかない案を選ぶと、ヒントの会話のあとで選び直せます。
- **町の人との寄り道**：針仕事帳（エルナ）、帰還札（オルフ）、白樺の待ち場（サエ）。吹雪の日を除いて、どの話でも進められます。
- **立ち話**：サエ、マロ、エルナ、オルフ、リツ、ユラは、話ごとに違うことを言います。出来事の合間に話しかけてみてください。

### 灯りの役目と、二人の仕事

灯り（護りの灯火）には、役目が二つあります。

- **外にいる者を導く**：雪で道が消えても、帰る方角が分かる目印。
- **中にいる者を護る**：灯術の火でつないだ灯りは、町を囲む「灯りの輪」になります。魔獣は、灯りと灯りの間を越えられません。森の灯台は輪の北の要、丘の灯台は西の要です。

灯りの芯と油は三日ともちません。灯守は毎日どこかの灯りを回って、芯を替え、油を足し、火を継ぎます。何も起きない日の見回りが、いちばん大事な仕事です。放っておかれた灯りが一つあれば、輪はそこで口を開け、魔獣が入ってきます。**ニナの灯術が輪をつなぎ、トウマの剣が、つなぐ者を守る。** 灯守が必ず二人一組で道に出るのは、そのためです。トウマの剣は師匠のサエから譲られたもので、「抜かずに済めばいちばん。だが、抜けないのでは火の番を守れない」と教わっています。

道で出会う相手は二種類います。

- **精霊**：消えた灯りのそばに、寒がって寄ってくるだけで、害はありません。温めると落ち着いて帰っていきます。
- **魔獣**：輪の切れ目を嗅ぎつけて山から下りてくる獣で、温めても落ち着きません。灯りそのものを倒して、口を広げようとします。

十二年前の大雪の晩、魔獣が森の灯台を倒して、輪を北で断ち切りました。当番だったサエは一晩じゅう魔獣を相手にして、灯台まで戻れませんでした。第8話の吹雪の晩、今度は西で輪が切れます。トウマは初めて本気で剣を抜き、魔獣「灯喰い（ひぐい）」と向き合います。灯喰いは灯りを持つニナを狙うので、トウマの「かばう」が要になります。

### 各話の戦闘

全10話のどの話にも、本筋の上に戦闘が一つ以上あります。第2〜7話と第9・10話は精霊、第8話は魔獣です。第4話と第7話は町や家の中に迷いこんだ精霊、第6話は小旅行の湖岸、第9話は祭りの鍋の湯気につられて来た精霊が相手です。

### 広がったフィールドと、道にいる精霊

本筋には必須でない、歩いて回れる場所を二つ足しています。

- **薬草の谷**：森の入口から西、白樺の待ち場の先（左下の「←」）。地面が温かく、冬でも薬草が育つ谷。コハルが毎朝通う場所で、奥の干し小屋には小さな場面があります。
- **峠の旧道**：丘の灯台の先（右上の「→」）。十二年前まで荷車が通っていた道。いちばん高い所に塚があり、番人を落ち着かせると、塚の灯籠をともす場面が見られます。吹雪の日（第8話）は入れません。

どちらにも、道の上に精霊がいます。話しかけると戦闘になり、落ち着かせると道からいなくなって、旅の手帳の「出会った精霊」に書きとめられます。よけて通ってもかまいません。

| 精霊 | 場所 | 特徴 |
|---|---|---|
| あられモチ（三匹） | 薬草の谷 | 一匹ずつは弱いが、数で来る。「灯の輪」でまとめて |
| みぞれヤドカリ | 薬草の谷 | 溶かした殻が、三ターンごとに凍り直す |
| モチとヤドカリ | 峠の旧道 | こごえモチと、こおりヤドカリの二体 |
| こだま番人 | 峠の旧道 | 若い番人。塚を守っている |

あられモチ・みぞれヤドカリ・こだま番人は、いまは既存の絵の色ちがいです。専用の絵の指示は `assets/MONSTER-ART-NOTES.md` にあります。

### 目的地の目印

次に行く場所には、足元に広がる輪と、上下に揺れる金色の矢印が出ます。目的地が別の地図にある時は、そこへ向かう出口に矢印が出て、右上の「いま、すること」に「▶ まず「森へ続く道」」のように行き方が添えられます。

## 演出のしくみ

台詞は `[話者, 文, ...]` の配列です。3番目以降に、表情（文字列）・きっかけ（オブジェクト）・選択肢（配列）を順不同で置けます。

```js
['nina','……なに、それ。','angry',{bgm:'quiet'}],
['','森の灯台に、あたたかな光が満ちた。',{flash:'warm',se:'lit',jingle:'lit',time:'dusk'}],
```

| きっかけ | 効果 |
|---|---|
| `bgm` | 曲の指定。`'silence'` で無音、`'scene'` で場面の曲へ戻す。会話が終わると自動で場面の曲に戻る |
| `se` / `jingle` | 効果音（配列で複数可）/ ジングル |
| `time` / `weather` | 時間帯（morning / day / dusk / night）/ 天気（blizzard）。会話の間だけ上書き |
| `shake` / `flash` / `fade` | 画面の揺れ / 白や暖色の閃光 / 暗転（`'night'` は長め） |
| `wait` / `slow` | 文字が出始めるまでの間（ミリ秒）/ 文字送りを遅くする倍率 |
| `emote` | マップ上の人物に吹き出しを出す |
| `still` | スチルを表示する（`'chapter-03'` など）。`null` で消す。会話が終わると自動で消える |

出来事（`at(...)`）にも `time` `weather` `bgm` を持たせられます。その出来事が「いま、すること」である間、歩いている時も同じ時間帯・天気・曲が続きます。

- **文字送り**：読点・句点・三点リーダーで少し止まります。文字送りの音は話す人で高さが変わります。語り（地の文）は台詞と別の枠で、中央寄せの明朝体です。
- **表情**：専用の顔グラは「通常・笑顔・照れ」の三種（住人は二種）。驚き・汗・怒り・沈む・疑問・思案・音符・ハートは、顔グラ＋記号で表します。記号は顔の横と、マップ上の本人の頭上に出ます。
- **時間帯の光**：夕暮れと夜は、画面全体に色をかけ、灯りのある所だけ明るくします。家の夜は、ストーブと食卓の灯りだけ。
- **端末の「動きを減らす」設定**では、文字送り・揺れ・吹雪の動きを抑えます。

音楽と効果音については `assets/MUSIC-NOTES.md` を参照してください。`music-preview.html` で全曲を試聴できます。

## 保存

このブラウザー、この開き方でのみ有効な端末内保存です。出来事の区切りと移動の終わりに自動保存します。会話の途中で閉じた場合は、その出来事の最初から再開します。戦闘中に閉じた場合は、その戦闘の前から再開します。

タイトルの「章を選んではじめる」は、通常の旅とは別の保存枠を使います。第10話は関係を選んでから始まります。「第6話の小旅行から」で氷湖の旅だけを試せます。

以前の版の保存データは、出来事の番号を変えていないので、そのまま続きから遊べます（台詞は新しいものになります）。旧四章版の保存データも、その進行のまま読みこめますが、**四章版でしか通らない水路と丘の会話は書き直していません**。

## 試作の範囲

- 全10話を結末まで遊べます。通しのプレイ時間は未計測です。
- 表情の専用画像は増やしていません。怒った顔・泣いた顔は、記号と色味で代用しています。
- 第3話の濁流、第8話の吹雪は、画面効果と効果音で表しています。人物が走る・板が流れるといった専用のアニメーションはありません。
- 技は最初から開放し、各戦闘をHP・MP満タンで始めます。薬草は戦闘ごとに三個補充します。
- マップの地形と建物は canvas の描画です。人物と精霊は専用画像です。
- スマートフォン実機は未確認です。

## テスト

```
node --test tests/*.test.cjs
```

戦闘ルール、保存データの検査、十話の進行（三つの結末まで）、寄り道と差し込み口、OP、音楽の切り替え、小旅行を検査します。

ローカルサーバーで開く場合は `node serve.cjs`（http://127.0.0.1:4173）。

## スマホと、ホーム画面への追加（PWA）

- 縦持ち：地図を上に置き、案内・会話・操作ボタンをその下に並べます。画面は流れません。
- 横持ち：地図を画面いっぱいに広げます。操作欄は出さず、地面を押して歩き、下の札（「E　〜」）を押して調べます。
- `manifest.webmanifest` と `sw.js` で、ホーム画面に追加して全画面で遊べます。一度開いた絵と音は端末に残るので、電波のない所でも開けます。
- ホーム画面への追加には、https で配信されている必要があります（`localhost` は例外）。`index.html` を直接開いた場合は使えません。
- アイコンは `assets/icons/`。タイトル絵から切り出しています。

## 地図

上の「地図」ボタン（キーボードは M）で、いつでも開けます。`maps.js` が描画エンジンで描いています。

- **ユキネのまわり**：北に粉ひきの森と森の灯台（北の要）、西に風待ちの丘と丘の灯台（西の要）、東に共同水路、南東に氷湖とミナモ。金色の点線が「灯りの輪」。いまいる場所に印が出て、灯台は灯したあと明るくなります。
- **世界の中のユキネ**：大陸と諸国の地図。ユキネはヒノワ王国の北の端、白嶺のふもと。王都セイカの大灯台を芯に、国じゅうの町が灯りの輪でつながる。西にミズハ連邦、東にカザネ氏族領、南西にコガネ公国、南の海にサザナ諸島。国の成り立ちは地図の下に出る（`maps.js` の `NATIONS`）。
