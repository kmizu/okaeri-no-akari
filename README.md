# おかえりの灯 — 帰り灯祭りまで・試作版

## 遊び方

このフォルダーの `index.html` をChromeまたはEdgeで開いてください。インストール不要、インターネット接続不要です。ZIPの場合は、先にすべて展開してください。

- 矢印キー / WASD：移動
- E / Enter：調べる、会話を進める
- Q：トウマとニナの先頭を交代
- J：旅の手帳
- 地面や人物をクリック：そこまで移動。調べられる対象には近づいて会話
- 下の矢印ボタン：画面上で移動
- 戦闘中：「たたかう」→トウマ→ニナの順にコマンドと対象を選ぶとターンが進みます
- 戦闘の操作：矢印キーで選択、Enter / Zで決定、Esc / Xで一段戻る。マウスでも選べます
- トウマは「とくぎ」、ニナは「じゅもん」から技を選びます。消費する力は画面ではMPと表示します
- 「どうぐ」から共有の薬草を使用できます。各戦闘で三個。HPを45回復します
- 行動結果は下のメッセージ欄で順番に表示し、HP・MPもそのタイミングで変化します。Enterで早送りできます
- 通常戦は「にげる」で確実に離脱できます。番人との戦闘では離脱できませんが、敗北後は道へ戻れます
- 音：右上の「音 OFF」で場面別BGMと効果音を有効化。もう一度押すと停止

## 今回入っている内容

町の支度と住人との会話 → 森の探索 → 小屋の昼食 → トウマの倒木移動 → ニナの橋修理 → 三つの戦闘 → 灯台点灯 → 帰還までの第一話。

第二話「水音の帰る道」：町の東口で依頼 → 共同水路 → トウマが水門を支える → ヤドカリ戦 → ニナが調整灯をつなぐ → 帰り灯点灯 → 町のマロへ報告。水番の休憩所では任意の幼馴染会話があります。第一話で出発札を戻すと第二話へ進めます。既存の第一話クリアデータも「つづきから」で引き継げます。

第三話「風待ちの丘」：町の西口 → トウマの風よけ修理 → 小屋のお弁当（任意） → 尾根の番人戦 → ニナのレンズ調整 → 丘の灯台点灯 → サエへの帰還報告。

最終話「帰り灯祭り」：マロのスープと、繕いものの籠での「帰り結び」を二人で楽しみ、東の帰り灯へ。トウマから告白／ニナの告白に返事／今の関係を大切にする、の三つの結末につながります。結末後も町に残れます。

二人のフェイス画像は、タイトル絵とは別の専用素材です。通常・笑顔・照れの各三表情を、一部の台詞に合わせて切り替えます。

トウマとニナの歩行グラフィックも専用素材です。前後左右それぞれ三枚、計24枚のポーズを使い、足の動きと進行方向を表示します。後ろの仲間は先頭が通った一つ前の地点を追います。

町のサエ・マロと、こごえモチ・こおりヤドカリ・枝角の番人も専用画像に更新しました。敵はマップと戦闘で同じ姿を表示します。

サエ・マロにも専用の会話用フェイスがあります。主人公と同じ水彩調で、通常／笑顔の2表情。帰還や料理を渡す場面では笑顔に切り替わります。`npc-faces-preview.html` で一覧を確認できます。

## 保存

このブラウザー、この開き方でのみ有効な端末内保存です。主要な出来事・移動終了時に自動保存します。会話の途中や戦闘の途中は再開対象ではありません。戦闘中に閉じた場合はその戦闘前から再開します。保存が禁止されているブラウザーでは、画面下に保存できない旨を表示します。

ファイルを直接開いた場合と、ローカルプレビューのURLで開いた場合では、保存場所が異なります。別のブラウザーへ移る場合も同様です。

## 試作の範囲

- 本編二時間分ではなく、四章から結末までの流れを遊べる制作途中の試作です。プレイ時間はまだ二時間に調整していません。
- 最終版のお守り・アイテム所持管理・図鑑・個別エンド絵は未実装です。薬草は戦闘ごとに補充する試作仕様です。
- 技は試用のため最初から開放し、各戦闘をHP・SP満タンで始めます。
- マップの地形と建物はゲーム側の簡易描画です。登場する町の住人と敵、トウマとニナは専用画像に更新済み。住人と敵は静止画を基本とし、こごえモチには小さな上下動があります。屋内休憩は会話で表現しています。
- エンディング画面は共通のキービジュアルを使います。
- BGM「窓辺の帰り灯」は約76秒のオリジナル曲。三拍子・76BPM、柔らかなピアノ風の旋律、低音、持続する和音、控えめなベルを重ねた合成音源です。ループ再生します。
- 最終的なプレイ時間は初見試遊で調整する予定です。

## タイトルの章選択

「章を選んではじめる」から四章の冒頭へ直接入れます。通常の旅とは別の保存枠を使用するため、通常の「つづきから」は残ります。「章選択の旅の続き」で試遊を再開できます。別の章を選ぶと章選択用の保存だけが置き換わります。途中章は必要な前章の出来事を完了した状態で始まります。

- `chapters.js`：章冒頭の状態
- `hill.js`：丘と祭りのイベント、結末

## 新しい住人

広場の南西には織り手エルナ、東側には配達人オルフがいます。専用チップと通常／笑顔の顔グラを備え、章の進行によって会話が変わります。会話は自由に楽しめるもので、進行の必須条件にはなりません。

## 町の人との寄り道

- 「針目の残る手帳」：エルナと話す → 森の休憩小屋の脇の道具箱 → エルナへ手帳を返す → 二人で表紙を繕う。糸の色を選べます。
- 「帰った人のしるし」：オルフと話す → 丘の小屋の脇で赤白の帰還札を修理 → オルフに報告。丘へは水路の仕事を終えてから進めます。
- どちらも依頼前の発見・修理に対応。必須ではなく、既存の結末条件は変わりません。祭りでは完了した寄り道に応じた後日談が聞けます。
- 進捗と行き先は旅の手帳の「町の人との寄り道」に表示します。古いセーブにも対応し、丘の灯台点灯後も丘へ戻れます。
- `side-stories.js` に寄り道の会話・選択・進行をまとめています。

## 背景の奥行き

建物の側面、厚い雪屋根、窓枠、玄関の段差、樹木の明暗、雪道の縁と影、水路の石積みを追加しました。人物とインタラクション対象は足元の位置で描画順を決めます。移動マスと通行判定は従来どおりです。`scenery-preview.html` から四つの背景を切り替えて確認できます。

## 場面ごとのBGM

OP・村・探索・戦闘の四曲を使用。森、水路、丘では「雪道の二重奏」、戦闘では「灯りのステップ」が流れ、戦闘を終えると探索曲へ戻ります。`music-preview.html` で四曲を試聴できます。

戦闘演出：斬撃、火花、灯の輪、連携の交差斬撃、被弾、回復、防御をメッセージと同期して表示します。動きを減らす端末設定にも対応。battle-preview.html でセーブを変えずに試せます。

## 森の拡張：白樺の待ち場

森の入口から西へ寄り道できます。トウマで古い道標を修理し、ニナで北側の待ち灯をともして、町のサエへ報告します。ベンチでは幼馴染の思い出を聞け、祭りではサエから後日談があります。進捗は旅の手帳に表示され、古いセーブでも訪問できます。本筋や恋愛エンドの条件には影響しません。


## 二人の家と各話の余韻

トウマとニナは親を亡くし、町の人に支えられて育った成人の幼馴染。空き家を手入れして二人暮らしをしています。町の南西の小さな家の前から入れます。共用の台所・食卓・薪ストーブ・繕い机と、それぞれの寝室を歩けます。

第1話と第2話の帰還報告後、第3話の祭り前、最終話の各結末後に帰宅シーンが入ります。食卓で終了済みの章の夜を再読できます。夜の途中で終了した場合は、その帰宅シーンの冒頭から再開します。古いセーブでも家へ入れます。
