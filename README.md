# おかえりの灯 — 十話の帰り道・試作版

## 遊び方

このフォルダーの `index.html` をChromeまたはEdgeで開いてください。インストール不要、インターネット接続不要です。ZIPの場合は、先にすべて展開してください。

- 矢印キー / WASD：移動
- E / Enter：調べる、会話を進める
- Q：トウマとニナの先頭を交代
- J：旅の手帳
- 地面や人物をクリック：そこまで移動。調べられる対象には近づいて会話
- 下の矢印ボタン：画面上で移動
- 戦闘中：「たたかう」→トウマ→ニナの順にコマンドと対象を選ぶとターンが進みます
- 戦闘の操作：矢印キーで選択、Enter / Zで決定、Esc / Xで一段戻る。マウスでも選べます
- トウマは「とくぎ」、ニナは「じゅもん」から技を選びます。消費する力は画面ではMPと表示します
- 「どうぐ」から共有の薬草を使用できます。各戦闘で三個。HPを45回復します
- 攻撃・魔法は一つの動作として進み、着弾時にHP・MPと状態が更新されます。ダメージ・回復量は対象の頭上に表示。Enter / Zまたは「早送り」で次の動作へ進めます
- 通常戦は「にげる」で確実に離脱できます。番人との戦闘では離脱できませんが、敗北後は道へ戻れます
- 音：右上の「音 OFF」で場面別BGMと効果音を有効化。もう一度押すと停止

## 今回入っている内容

全10話の試作です。二人の家の朝 → 広場で仕事の相談 → 森の探索と灯台の修理が第1話。第2話からは、水路の点検、幼い頃の思い出、町の人への届け物、春の研修、小旅行を通して二人の暮らしを描きます。詳しい進行は下の「十話構成への拡張」を参照してください。

第3話の喧嘩はその日のうちに仲直りします。第9話の祭りで、トウマから告白／ニナから告白／今の関係を大切にする、を選び、第10話の訪問先や会話が変わります。各話の最後は二人の家へ帰ります。

従来の四章版の保存データは、その進行のまま続けられます。

二人のフェイス画像は、タイトル絵とは別の専用素材です。通常・笑顔・照れの各三表情を、一部の台詞に合わせて切り替えます。

トウマとニナの歩行グラフィックも専用素材です。前後左右それぞれ三枚、計24枚のポーズを使い、足の動きと進行方向を表示します。後ろの仲間は先頭が通った一つ前の地点を追います。

町のサエ・マロと、こごえモチ・こおりヤドカリ・枝角の番人も専用画像に更新しました。敵はマップと戦闘で同じ姿を表示します。

サエ・マロにも専用の会話用フェイスがあります。主人公と同じ水彩調で、通常／笑顔の2表情。帰還や料理を渡す場面では笑顔に切り替わります。`npc-faces-preview.html` で一覧を確認できます。

## 保存

このブラウザー、この開き方でのみ有効な端末内保存です。主要な出来事・移動終了時に自動保存します。OPは家と広場それぞれの場面の冒頭から、十話版の会話はそのイベントの冒頭から再開します。戦闘中に閉じた場合はその戦闘前から再開します。保存が禁止されているブラウザーでは、画面下に保存できない旨を表示します。

ファイルを直接開いた場合と、ローカルプレビューのURLで開いた場合では、保存場所が異なります。別のブラウザーへ移る場合も同様です。

- 全10話から結末までを遊べる制作途中の試作です。プレイ時間はまだ二時間に調整していません。
- 最終版のお守り・アイテム所持管理・図鑑・個別エンド絵は未実装です。薬草は戦闘ごとに補充する試作仕様です。

- BGM「窓辺の帰り灯」は約76秒のオリジナル曲。三拍子・76BPM、柔らかなピアノ風の旋律、低音、持続する和音、控えめなベルを重ねた合成音源です。ループ再生します。

## 新しい住人

広場の南西には織り手エルナ、東側には配達人オルフがいます。専用チップと通常／笑顔の顔グラを備え、章の進行によって会話が変わります。会話は自由に楽しめるもので、進行の必須条件にはなりません。

## 町の人との寄り道

- 「針目の残る手帳」：エルナと話す → 森の休憩小屋の脇の道具箱 → エルナへ手帳を返す → 二人で表紙を繕う。糸の色を選べます。
- 「帰った人のしるし」：オルフと話す → 丘の小屋の脇で赤白の帰還札を修理 → オルフに報告。丘へは水路の仕事を終えてから進めます。
- どちらも依頼前の発見・修理に対応。必須ではなく、既存の結末条件は変わりません。祭りでは完了した寄り道に応じた後日談が聞けます。
- 進捗と行き先は旅の手帳の「町の人との寄り道」に表示します。古いセーブにも対応し、丘の灯台点灯後も丘へ戻れます。
- `side-stories.js` に寄り道の会話・選択・進行をまとめています。

### 二人で考える場面

### 帰り道の寄り道

十話版の第2・4・6・8話に、任意の小話を追加しました。次のイベントを読み終えると、「少し寄り道する／今日は用事の続きへ」を選べます。

- 第2話・点検板を確かめた後「点検帳の、空いた欄」：リツの修業時代と、三人で残す点検の記録。
- 第4話・薬瓶を返した後「薬袋に入らないもの」：ユラの往診、幼い頃の毛布、休む側になること。
- 第6話・旅行鞄の内袋を選んだ後「出さない手紙」：二人が書き直す本音と、春に一緒に取りつける玄関灯。
- 第8話・救援の灯りを合わせた後「帰る人の、手荷物」：町から預かったスープと手袋を、二人も受け取る帰り道。

小話を最後まで読んでから、手帳の「二人の思い出」に記録します。その夜の食卓と第9話の祭りで会話が増え、「出さない手紙」は三つの第10話にもそれぞれ反映されます。途中で閉じると元のイベントから再開できます。旧セーブのイベント番号はそのまま使えます。すでに該当イベントを終えたセーブで追加分を試す場合は、タイトルの章選択から開始してください。

### 第6話の小旅行「氷湖の迎え灯」

第6話の旅行鞄と手紙の用意を終えると、湖岸の旧街道を歩き、渡し場の集落ミナモと古い灯守小屋を訪れます。新マップは3つ。湖には降りず、岸の街道を進みます。早く試す場合は、タイトルの「章を選んではじめる」から「第6話の小旅行から」を選んでください。通常の旅とは別枠の保存を使います。

古い灯守小屋で役割を決めると、トウマは湖岸、ニナは小屋に分かれます。Qまたは交代ボタンで操作する人物と場所を切り替えます。それぞれの場所も保存されます。

1. トウマが反射板を直すと、ニナの小屋へ光が届きます。
2. ニナが共鳴灯を合わせると、トウマ側の留め輪が温まります。
3. トウマが風よけを開くと、ニナの応答灯を使えます。
4. ニナが光を送ると、遠い岸から返事があります。小屋の出口で合流します。

合流した二人は港で豆スープと黒パンを食べ、街道を歩いてユキネへ戻ります。家の食卓で第6話の締めへつながり、祭りにもミナモから便りが届きます。帰り灯が各地の暮らしとつながる謎と、地図の外へ広がる世界を描く小旅行です。

旧セーブとイベント番号を維持しています。既に第6話の食卓まで進んだ場合は小旅行を自動挿入しません。章選択から試せます。新マップの景色と道具は既存の2.5D風canvas描画で制作し、`journey.js` に進行・地形・会話、`journey-art.js` に背景と仕掛けをまとめています。

### クオータービューの戦闘（2026-11-12）

味方二人を右手前、精霊を左奥へ配置した斜め見下ろしの戦闘画面です。トウマとニナに待機・行動・防御の専用グラフィックを追加。コマンド、メッセージ、HP・MPは画面下にまとめています。入力中の人物を足元の輪で、選択中の対象を頭上の印で示します。対象はメニューからも戦場の人物・精霊をクリックしても選べます。

二人の行動を決めてからターンが進む仕組み、技の効果・MP・連携・敵の行動は従来どおり。斬撃では攻撃役が踏み込み、魔法は術者から対象へ飛びます。被弾・回復の演出はステータス欄ではなく戦場の人物へ表示します。「動きを減らす」の端末設定では移動と光の演出を抑えます。

`battle-preview.html` でこごえモチ・こおりヤドカリ・枝角の番人を切り替えて試せます。本編の保存は変更しません。新しい戦闘素材と生成時の制作指示は `assets/BATTLE-ART-NOTES.md` に記載しています。

### 戦闘の動きと状態表示

踏み込み・振り抜き・戻り、詠唱・弧を描く光・着弾をつないで再生します。技名は短く表示して消え、ダメージや回復量はキャラクターの頭上へ独立して浮かびます。戦闘中の古いコマンド札や数値メッセージは残しません。全体魔法は一回の詠唱で全対象へ届きます。

氷の殻は半透明の氷膜、冷えは青みと足元の霜、体勢崩れは頭上の星、灯りの剣は金色の光、防御・かばうは盾で表します。状態名の印も併記し、解除・消費・期限切れに合わせて消します。氷を溶かすと氷片が散り、回復で冷えを治すと霜が消えます。

早送りした場合もHPや状態は正しい結果まで進みます。プレビューの敵を切り替えた場合は、前の演出を中止します。「動きを減らす」設定では移動や光の演出を止め、頭上の数字と状態の印は表示します。
