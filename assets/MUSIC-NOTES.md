# 音楽について

BGMは `tools/compose_music.py` で作曲・録音しています。スクリプトがMIDIを組み立て、FluidSynth と SoundFont（FluidR3_GM）で演奏を録音し、継ぎ目のないループに切り出して `assets/music/*.ogg` に書き出します。外部の楽曲・録音サンプルは使っていません（演奏はサンプル音源で、生演奏ではありません）。

```
python3 tools/compose_music.py            # 全曲を録音し直す
python3 tools/compose_music.py tender     # 一曲だけ
python3 tools/compose_music.py --check    # 長さと、半音でぶつかる音の検査
```

必要なもの：fluidsynth、ffmpeg、FluidR3_GM.sf2、Python の mido と numpy。

## 再生のしくみ（music.js）

- 場面ごとの曲（base）と、台詞に添えた指定（cue）の二層。cue が立っている間は cue の曲が鳴り、会話が終わると場面の曲へ戻ります。`bgm:'silence'` は無音の指定です。
- 出来事ごとに `bgm` を持たせると、その出来事が「いま、すること」である間、歩いている時も同じ曲が続きます（事故の間じゅう「薄氷」、など）。
- 切り替えは 1.2 秒のクロスフェード。音は初期OFFで、右上の「音」ボタンで有効にします。

## 効果音と環境音（sfx.js）

すべて WebAudio の合成です。文字送りの音は話す人で高さが変わります（トウマは低め、ニナは高め）。環境音は場所と天気で切り替わります：家は薪のはぜる音、森と丘は風、水路は水音（事故の間は濁流）、吹雪、祭りのざわめき。
