# 窓辺の帰り灯

この試作版のために作曲したオリジナルBGM。外部の楽曲・録音サンプルは使用していません。

- 用途：村の探索・会話・祭り
- 情景：雪の静けさ、暖炉のぬくもり、幼馴染と歩く帰り道
- 76BPM / 三拍子 / ト長調を中心とした32小節
- 再生時間：約75.79秒。末尾の余韻を先頭に循環させたループ
- 音色：柔らかなピアノ風の旋律と分散和音、低音、薄い持続和音、控えめなベル
- データ：winter-hearth.wav / 24kHz / ステレオ / 16bit PCM
- ゲーム内再生音量：32％。音ボタンで再生・一時停止。再開時は続きを再生

合成後にクリッピングがないこと、有限値のみであること、ループ境界の波形差が小さいことを確認しています。

## 雪明かりの約束

タイトル画面と冒頭会話のためのオリジナルOP曲。外部楽曲・録音サンプルは使用していません。

- 68BPM / 四拍子 / ニ長調を中心とした24小節、約84.71秒
- ベルの導入、柔らかい持続和音とピアノ風旋律。中盤で分散和音と旋律の音域が広がる構成
- snowbound-promise.wav / 24kHz / ステレオ / 16bit PCM / ループ対応
- 冒頭会話の終了時に村の曲へ1.2秒でクロスフェード。「つづきから」は村の曲、タイトルへ戻るとOP曲
- 音は初期OFF。「音 ON」で再生し、OFF中の場面変更は無音を維持

## 雪道の二重奏

- 森・共同水路・丘の探索と会話に使用。88BPM、6拍のフレーズによる16小節、約65.45秒
- 笛に似た柔らかな持続旋律、控えめな分散和音、低音とベル。オリジナル合成音源
- snowpath-duet.wav / 24kHz / ステレオ / 16bit PCM

## 灯りのステップ

- 全戦闘に使用。108BPM、四拍子24小節、約53.33秒
- ホ短調を軸に、中盤はト長調の明るい響き。ピアノ風の旋律、動く低音、柔らかな打楽器。オリジナル合成音源
- lantern-step.wav / 24kHz / ステレオ / 16bit PCM

探索から戦闘へ、勝利・逃走・敗北後の帰路から探索へクロスフェード。探索曲は中断した位置から戻ります。村への帰還・タイトルへの移動にも追従します。全曲初期OFF、再生操作は音ボタンから。新曲はクリッピングなし・有限値・ループ境界差0.03未満を確認。
