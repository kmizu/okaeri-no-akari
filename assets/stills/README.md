# イベントスチル制作記録

各章1枚（全10枚）と、想定されている5エンディング各1枚、計15枚を制作。組み込み image_gen を使用し、主役は既存の `cover.png` と `faces.png`、コハルは承認済みの正式な `koharu-faces.png` を人物参照にした。横長16:9相当、1672×941のPNG。下側には台詞を重ねることを想定した比較的静かな領域を確保。画像自体に文字は入れていない。

[画像一覧を開く](index.html)。各画像をクリックすると原寸で表示できる。

## エンディングの表示候補

`touma`・`nina` は告白した側が異なる恋人ルート、`friends` は関係の名前をまだ決めない二人、`koharu` は恋愛の返事を保留した上で三人の仲と相方としての関係を大切にするルート、`both` は葛藤と話し合いを経て三人で恋愛関係を選ぶルート。画像もその違いを反映した。

| ルート | 絵 | 表示する想定の場面 | 台本の参照 |
|---|---|---|---|
| `touma` | [結末：トウマから告白](ending-touma.png) | 少し背伸びをして、トウマの頬に短く触れる。 | `episodes-data.js routes.touma[3]` |
| `nina` | [結末：ニナから告白](ending-nina.png) | ニナは指先を重ねて、それからしっかり握り直した。 | `episodes-data.js routes.nina[2]` |
| `friends` | [結末：名前はまだつけない](ending-friends.png) | ニナは残ったお茶を、二つのカップに分けた。 | `episodes-data.js routes.friends[3]` |
| `koharu` | [結末：三人で仲良く](ending-koharu.png) | 次に吹雪で泊まる時は、三人だ。 | `episodes-data.js routes.koharu[2]` |

エンディング専用絵は、最後の画面の一律背景ではなく、各ルートの上記の場面で表示することを想定している（ニナルート・三人で仲良くルートは最終話の途中の場面）。結末の意味を代表する絵として制作した。

## 保存・生成指示・検証

- `production.json`：15点それぞれの実際の生成指示全文、参照画像、台本の参照と表示候補。`gameIntegration: false` は未組み込みであることを示す。
- `manifest.json`：完成15点と参照画像のSHA-256、寸法、章・ルート対応。
- すべて組み込み画像生成ツールで制作。生成したPNGをそのまま保存し、後から人物や背景を描き足す加工はしていない。
- 生成結果で人物の髪型・衣装・人数、関係に合う仕草、場面を目視確認。コハルは承認された丸い頬・亜麻色の低い二つ結び・若草色の首巻きのデザインに統一。
- PNG15点の読み込み、16:9相当の寸法、ファイルの重複なし、全10章と全5ルートの対応、ハッシュ、一式のリンク先を確認。
- ゲームの台本・分岐・セーブデータは変更していない。台詞への表示キューやスチル表示UI、鑑賞モードは別途組み込みが必要。
