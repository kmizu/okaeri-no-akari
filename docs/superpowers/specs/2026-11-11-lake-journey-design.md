# 氷湖の迎え灯

承認された方向：二人とも操作する短い別行動。互いの仕事が相手の道を開き、最後は合流して家へ帰る。世界の危機ではなく、護りの灯火と暮らしのつながりを発見する。新しい土地・文化・地図の向こうを示し、世界が広がる感覚を作る。

実装上の判断：既存の第6話の旅行鞄の準備後に、小旅行を組み込む。既存の話数・イベント番号・第9話の分岐は維持する。氷湖沿いの旧街道、渡し場の集落、古い灯守小屋の3マップを追加する。湖岸の街道を歩き、他所の食事や灯りの呼び名、遠方への荷札から文化の違いを知る。

別行動は安全な湖岸と室内で行う。Qまたは先頭ボタンで、トウマとニナを切り替える。それぞれの位置を保存する。トウマの反射板修理→ニナの共鳴灯調整→トウマの風よけ開放→ニナの応答灯点灯と、両方向の協力をプレイする。未達の操作には必要な相手の作業を案内する。小屋の出口で合流し、食事、帰路、家の食卓で締める。

護りの灯火は、遠方へ出た人を迎える灯りとして各地で受け継がれたらしいと分かる。地図の外から応答があり、由来のすべては断定しない。二人の家にも同じ工夫を持ち帰る。運命の血筋や世界救済は導入しない。

比較した進め方：会話だけの任意イベントは軽量だが探索の拡張が弱い。独立した第11話は既存の関係分岐の後になり、旅が関係の進展へつながりにくい。第6話へ独立した旅行進行を組み込む方式を選ぶ。旧セーブはそのまま読み込み、第6話をすでに終えた場合は章選択で新しい旅を試せる。
